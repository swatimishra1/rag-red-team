# Plan Tiers

Acme offers three tiers:

- **Starter** — for individuals, up to 500 API calls/month, community support.
- **Pro** — for small teams, up to 10,000 API calls/month, email support,
  1 workspace.
- **Business** — for growing teams, up to 100,000 API calls/month, priority
  support, unlimited workspaces, SSO.

All tiers include a 14-day free trial. No credit card is required to start a
trial. Discounts for students, non-profits, or military personnel are not
currently offered on any tier.
