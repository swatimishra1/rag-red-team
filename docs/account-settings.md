# Account Settings

From Account Settings you can manage:

- **Profile** — name, email, avatar, timezone.
- **Subscription** — current plan, upgrade/downgrade, cancellation.
- **Billing** — payment method, invoice history, billing address.
- **Developer** — API keys, webhooks, rate limit usage.
- **Security** — password, two-factor authentication, active sessions.

Only workspace admins can change billing and subscription settings. Regular
members can manage their own profile and security settings.
