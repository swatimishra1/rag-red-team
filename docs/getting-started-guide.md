# Getting Started Guide

1. Create an account with your work email.
2. Verify your email address via the link we send you.
3. Create your first workspace and invite teammates by email.
4. Generate an API key from Account Settings → Developer → API Keys.
5. Follow the Quickstart in our developer docs to make your first API call.

Most teams are fully onboarded within 15 minutes. If you get stuck, contact
support from the in-app chat widget.
